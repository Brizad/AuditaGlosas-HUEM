Cargar lote de facturas

Suba el archivo JSON con las facturas y su RIPS (Res. 2275 de 2023). El sistema revisa la estructura, guarda el lote y lo valida con las reglas activas.

1Elija el archivo

¿Qué estructura debe tener el archivo?

Una lista [ ] de facturas como esta (también se acepta { "facturas": [ ] }). Puede usar data/lote_demo.json como ejemplo.

[
  {
    "numFactura": "FV-1002",
    "eps": "EPS-ALFA",
    "fechaExpedicion": "2026-06-12",
    "valorTotal": 47500,
    "items": [
      { "codigo": "890201", "cantidad": 1, "valorUnitario": 38000 },
      { "codigo": "903841", "cantidad": 1, "valorUnitario": 9500 }
    ],
    "soportes": ["Resultado de laboratorio"],
    "rips": {
      "numFactura": "FV-1002",
      "usuarios": [
        {
          "servicios": {
            "consultas":      [ { "codConsulta": "890201", "vrServicio": 38000, "numAutorizacion": null } ],
            "procedimientos": [ { "codProcedimiento": "903841", "vrServicio": 9500, "numAutorizacion": null } ],
            "medicamentos":   [ ]
          }
        }
      ]
    }
  }
]

El documento del paciente, si viene en el RIPS, no se guarda (Ley 1581 de 2012).

2Describa el lote

Si no indica el periodo, se toma del mes de las facturas.
